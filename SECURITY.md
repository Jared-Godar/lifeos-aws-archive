# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability or accidental
exposure. Use GitHub's **Report a vulnerability** option on the repository's
Security tab so the report and any follow-up remain private.

Include the affected file or component, reproduction steps, potential impact,
and any suggested mitigation. Reports will be acknowledged as soon as
practicable.

## Scope

This repository contains infrastructure templates and local automation. Never
include AWS credentials, account-specific identifiers, private bucket names, or
personal file paths in reports, examples, logs, manifests, or pull requests.
